# BrandPulse AI — Live Demo

**Live Application:**
https://brandpulse-ai-sentiment-analysis-xuor.onrender.com/

BrandPulse AI is successfully deployed and publicly accessible through Render.

The application provides sentiment analysis and brand intelligence features using the trained TF-IDF and Logistic Regression model. The trained model artifacts are included in the project repository, so no retraining is required to run the deployed application.
